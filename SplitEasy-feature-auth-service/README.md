# SplitEasy

SplitEasy is a web platform that simplifies shared expense management for groups such as friends, roommates, or travelers.

Users can create a group, register expenses, and track who paid and how much. The system automatically calculates the optimal way to settle debts with the minimum number of transfers.

The platform also includes an AI agent that can answer questions about the group's balances and expenses.

## Purpose of the project

This project was developed as an academic exploration of modern backend architecture concepts, including:

- Asynchronous microservices
- Message brokers
- Serverless functions
- AI-powered agents
